# HR Analytics SQL Project

## Project Overview
This project analyzes Human Resources data using MySQL to identify workforce trends and generate insights that support HR decision-making.

## Tools Used
- MySQL
- MySQL Workbench 8.0

## Database
The database contains 10 tables:

- employees
- departments
- job_roles
- locations
- attendance
- employee_exits
- performance_reviews
- promotions
- recruitment
- salary_history

The complete database setup and sample data are available in:
`database/hr_analytics_project_all_in_one.sql`

## Analysis Areas

1. Attrition Analysis
2. Performance Reviews Analysis
3. Attendance Analysis
4. Salary History Analysis
5. Promotions Analysis
6. Recruitment Analysis
7. Employee Analysis

## Key Skills Demonstrated
- SQL Queries
